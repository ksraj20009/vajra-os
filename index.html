How to Install

1. Download ISO — Boot Vajra OS (Recommended)

Download the ISO from the release page and burn it to a USB drive. Boot any computer from USB — no installation needed.

dd if=vajra-os-1.0-amd64.iso of=/dev/sdX bs=4M status=progress # Or use Rufus on Windows: https://rufus.ie

Vajra OS runs completely from USB. You don't need to install anything on your hard drive.

2. Try with Docker (No reboot needed)

docker import vajra-os-rootfs.tar.gz vajra-os docker run -it vajra-os /bin/bash

3. Install Vajra tools on existing Linux (Optional)

This installs Vajra tools on your existing Debian/Ubuntu system. It does NOT replace your OS.

curl -fsSL https://ksraj20009.github.io/vajra-os/apt-repo/vajra-archive-keyring.asc | gpg --dearmor -o /usr/share/keyrings/vajra-archive-keyring.gpg echo "deb [signed-by=/usr/share/keyrings/vajra-archive-keyring.gpg] https://ksraj20009.github.io/vajra-os/apt-repo vajra main" | sudo tee /etc/apt/sources.list.d/vajra.list sudo apt update sudo apt install vajra-core vajra-buddhi-ai vajra-security-center
