Why Vajra OS?

Privacy First

No tracking, no telemetry, no cloud dependencies. Tor integration for anonymous browsing. Your data stays on your machine.

Buddhi AI

Built-in AI assistant with voice commands and agentic capabilities. Runs locally, no internet required for core functions.

Indian at Core

GST calculator, Panchang, Vedic mathematics, Ayurveda health tips, festival calendar, IRCTC train status — all built in.

Beginner and Pro Modes

Beginner mode has safety guardrails that block dangerous commands. Pro mode gives full access for advanced users.

10 Indian Languages

Hindi, Tamil, Bengali, Gujarati, Punjabi, Kannada, Telugu, Malayalam, Marathi, Sanskrit — full font and input support.

Cybersecurity Tools

Pentesting tools with ethical usage guides. Network scanner, vulnerability checker, firewall manager, intrusion detection.

Quick Install (APT)

curl -fsSL https://ksraj20009.github.io/vajra-os/apt-repo/vajra-archive-keyring.asc | gpg --dearmor -o /usr/share/keyrings/vajra-archive-keyring.gpg echo "deb [signed-by=/usr/share/keyrings/vajra-archive-keyring.gpg] https://ksraj20009.github.io/vajra-os/apt-repo vajra main" | sudo tee /etc/apt/sources.list.d/vajra.list sudo apt update sudo apt install vajra-core vajra-buddhi-ai vajra-security-center

vajra-core - Core OS utilities (process, memory, filesystem managers) vajra-buddhi-ai - AI assistant with local processing vajra-security-center - Security scanning, firewall, intrusion detection vajra-control-center - System settings and configuration vajra-package-manager - Package management frontend vajra-update-manager - System update manager vajra-keyring - GPG repository signing key vajra-desktop - Desktop environment meta-package (Xfce4) vajra-wallpapers - Official Vajra OS wallpapers
